# Andrej Karpathy Guidelines — Coding Behavior Skill

This skill is installed as the project's root `CLAUDE.md`. It applies automatically to every session.

## The Four Principles (summary)

| Principle | Rule |
|-----------|------|
| **Think Before Coding** | State assumptions, surface confusion, present alternatives |
| **Simplicity First** | Minimum code only — no speculative features, abstractions, or configurability |
| **Surgical Changes** | Touch only what the request requires; preserve existing style |
| **Goal-Driven Execution** | Define verifiable success criteria; loop until met |

## Anti-patterns this prevents

- Silent assumptions leading to wrong implementations
- Overcomplicated first drafts that need rewrites
- Drive-by refactoring of unrelated code
- Vague tasks with no measurable completion
